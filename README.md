# 教学质量综合评价系统

本项目提供一个使用 C++ 编写的控制台程序，演示以马尔科夫过程和模糊综合评价为核心的教学质量评价流程。程序会生成期中、期末随机教评数据，并展示从转移矩阵到最终评分的全部计算步骤。

## 编译与运行

```bash
g++ -std=c++17 -O2 -o evaluator main.cpp
./evaluator
```

运行后将看到以下输出片段：

1. **数据生成**：10 个指标的期中与期末随机评分均值。
2. **计算步骤**：每个指标的一步转移矩阵、平稳分布、隶属度向量。
3. **权重**：基于随机重要度得分归一化得到的指标权重。
4. **评价结果**：汇总后的教学质量评定向量与最终评分（百分制）。
